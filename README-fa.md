# 🤖 ربات هوش مصنوعی تلگرام

یک ربات تلگرام کامل با قابلیت‌های هوش مصنوعی، مدیریت وظایف، یادآورها، ترجمه و تولید تصویر — با امکان میزبانی رایگان در Hugging Face Spaces و Render.

## ✨ امکانات

### 🧠 **گفتگوی هوشمند**
- گپ هوشمند با حافظه متنی و تاریخچه مکالمه
- خلاصه‌سازی خودکار مکالمات طولانی برای حفظ زمینه
- قابلیت بینایی: تحلیل و بحث درباره تصاویر
- پشتیبانی از چت خصوصی و گروهی با @منشن
- پشتیبانی کامل از زبان فارسی با رمزگذاری UTF-8

### 📝 **سیستم مدیریت وظایف**
- ایجاد وظایف با سطوح اولویت (بالا، متوسط، عادی)
- دسته‌بندی وظایف (کاری، شخصی، عمومی)
- تعیین مهلت سفارشی با پشتیبانی از منطقه زمانی ایران (UTC+3:30)
- اعلان خودکار انقضای مهلت
- مدیریت مشارکتی وظایف در گروه‌ها
- صفحه‌کلید تعاملی برای تکمیل/حذف وظایف

### ⏰ **سیستم یادآوری هوشمند**
- زمان‌بندی یادآورها با فرمت‌های انعطاف‌پذیر:
  - نسبی: `45m`، `2h`، `3d`
  - ساعت مطلق: `18:30` (وقت ایران)
  - تاریخ و ساعت کامل: `2026-07-15 10:00`
- فواصل تکرار سفارشی: روزانه، هفتگی یا سفارشی (مثلاً `12h`، `3d`)
- اهداف منشن: اعلان به خودتان یا همه اعضای گروه
- امکان به تعویق انداختن و رد کردن

### 🌐 **سرویس ترجمه**
- ترجمه حرفه‌ای بین بیش از 25 زبان
- OCR + ترجمه برای تصاویر
- ترجمه‌های دقیق متناسب با زمینه و فرهنگ
- پشتیبانی از اصطلاحات فنی
- تشخیص خودکار زبان مبدأ

### 🎨 **تولید تصویر با هوش مصنوعی**
- تولید تصاویر با کیفیت بالا از متن
- استفاده از مدل Agnes Image 2.0 Flash
- خروجی با وضوح 1024x1024

### 🛡️ **حفاظت داخلی**
- محدودیت نرخ (به ازای هر کاربر و سراسری)
- حفاظت ضد اسپم با خاموشی خودکار
- پایگاه داده SQLite ایمن با حالت WAL
- نظارت خودترمیم بی‌نهایت

## 🔌 پیکربندی API

این ربات از **API سایت agnes-ai.com** برای قابلیت‌های هوش مصنوعی استفاده می‌کند. شما می‌توانید به راحتی آن را برای استفاده از هر API سازگار دیگری تنظیم کنید:

**ارائه‌دهنده API فعلی:**
- وب‌سایت: [https://agnes-ai.com/](https://agnes-ai.com/)
- برای دریافت کلید API ثبت‌نام کنید
- متغیر محیطی `AGNES_API_KEY` را تنظیم کنید

**استفاده از APIهای جایگزین:**
شما می‌توانید از هر API سازگار با OpenAI با تغییر این متغیرهای محیطی استفاده کنید:
- `CHAT_API_BASE` - نقطه پایانی API چت شما
- `IMAGE_API_BASE` - نقطه پایانی تولید تصویر شما
- `CHAT_MODEL` - نام مدل چت ترجیحی شما
- `IMAGE_MODEL` - نام مدل تصویر ترجیحی شما

سازگار با: OpenAI، Anthropic، Google AI، Azure OpenAI و سایر نقاط پایانی سازگار با OpenAI.

## 🚀 شروع سریع

### 1. کلون کردن مخزن

```bash
git clone https://github.com/mahdikiani-2007/telegram-ai-chat-bot.git
cd telegram-ai-chat-bot
```

### 2. نصب وابستگی‌ها

```bash
pip install -r requirements.txt
```

### 3. پیکربندی متغیرهای محیطی

فایل نمونه محیط را کپی کرده و اطلاعات خود را وارد کنید:

```bash
cp .env.example .env
```

فایل `.env` را با ویرایشگر متنی دلخواه خود ویرایش کنید:

```env
# ضروری
TELEGRAM_TOKEN=your_telegram_bot_token_here
AGNES_API_KEY=your_agnes_api_key_here

# اختیاری (مقادیر پیش‌فرض ارائه شده)
CHAT_API_KEY=your_chat_api_key_here
IMAGE_API_KEY=your_image_api_key_here
CHAT_API_BASE=https://router.bynara.id/v1
AGNES_BASE=https://apihub.agnes-ai.com/v1
CHAT_MODEL=mimo-v2.5-free
IMAGE_MODEL=agnes-image-2.0-flash
```

**نحوه دریافت اطلاعات احراز هویت:**
- **TELEGRAM_TOKEN**: با [@BotFather](https://t.me/botfather) در تلگرام صحبت کنید و یک ربات جدید بسازید
- **AGNES_API_KEY**: در [Agnes AI](https://agnes-ai.com) ثبت‌نام کنید تا کلید API خود را دریافت کنید (یا از ارائه‌دهنده API خودتان استفاده کنید)

### 4. اجرای ربات

```bash
python bot.py
```

ربات شروع به کار کرده و شروع به گوش دادن به پیام‌ها می‌کند!

## ☁️ استقرار رایگان (Hugging Face Spaces + Render)

### گزینه 1: Hugging Face Spaces (توصیه می‌شود)

1. یک Space جدید در [Hugging Face](https://huggingface.co/spaces) ایجاد کنید
2. **Docker** را به عنوان SDK انتخاب کنید
3. فایل‌های کد خود را آپلود کنید
4. متغیرهای محیطی را در Space Settings → Variables تنظیم کنید
5. دایرکتوری ذخیره‌سازی دائمی `/data` به طور خودکار در دسترس خواهد بود

### گزینه 2: Render

1. یک Web Service جدید در [Render](https://render.com) ایجاد کنید
2. مخزن GitHub خود را متصل کنید
3. دستور Build را تنظیم کنید: `pip install -r requirements.txt`
4. دستور Start را تنظیم کنید: `python bot.py`
5. متغیرهای محیطی را در داشبورد Render اضافه کنید
6. استقرار دهید!

**نکته:** ربات شامل یک سرور بررسی سلامت در پورت 7860 برای نظارت بر زمان فعال است.

## 📚 دستورات موجود

### دستورات عمومی

| دستور | توضیحات | مثال |
|---------|-------------|---------|
| `/start` | نمایش پیام خوش‌آمد و معرفی ربات | `/start` |
| `/reset` | پاک کردن تاریخچه چت و حافظه مکالمه (فقط ادمین در گروه‌ها) | `/reset` |

### امکانات هوش مصنوعی

| دستور | توضیحات | مثال |
|---------|-------------|---------|
| **چت** | فقط یک پیام ارسال کنید یا ربات را در گروه‌ها منشن کنید | `@botname فیزیک کوانتومی را توضیح بده` |
| `/pic [prompt]` | تولید یک تصویر هوش مصنوعی از توضیحات متنی | `/pic یک غروب آفتاب بر فراز کوه‌ها` |
| `/tr [lang] [text]` | ترجمه متن به زبان مقصد | `/tr en سلام دنیا` |
| `/tr` (روی تصویر) | OCR و ترجمه متن از تصویر | عکس را با کپشن `/tr en` ارسال کنید |

### مدیریت وظایف

| دستور | توضیحات | مثال |
|---------|-------------|---------|
| `/todo [task]` | ایجاد یک وظیفه جدید (جریان تعاملی) | `/todo خرید مواد غذایی` |
| `/todos` | نمایش لیست وظایف فعال با دکمه‌های مدیریتی | `/todos` |

### یادآورها

| دستور | توضیحات | مثال |
|---------|-------------|---------|
| `/remind [text]` | ایجاد یک یادآور جدید (جریان تعاملی) | `/remind جلسه تیم` |

## 🎯 نمونه‌های استفاده

### ایجاد یک وظیفه

```
/todo اتمام گزارش پروژه
```

ربات شما را راهنمایی می‌کند:
1. انتخاب اولویت (بالا/متوسط/عادی)
2. انتخاب دسته (کاری/شخصی/عمومی)
3. تعیین مهلت (اختیاری)

### تنظیم یادآور

```
/remind تماس با دندانپزشک
```

جریان تعاملی:
1. انتخاب زمان اجرا (10m، 30m، 1h، 3h، فردا 9 صبح یا سفارشی)
2. انتخاب هدف منشن (فقط من / همه اعضا)
3. تنظیم تکرار (یک‌بار، روزانه، هفتگی یا فاصله سفارشی)

### ترجمه

```
# ترجمه متن
/tr en این یک متن فارسی است

# ترجمه تصویر (ارسال عکس با کپشن)
/tr en
```

### تولید تصویر

```
/pic یک شهر آینده‌نگرانه در شب با چراغ‌های نئون
```

## 🗄️ ساختار پایگاه داده

ربات از SQLite با جداول زیر استفاده می‌کند:

- **messages**: تاریخچه مکالمات
- **summaries**: خلاصه‌های فشرده مکالمه
- **todos**: داده‌های مدیریت وظایف
- **reminders**: یادآورهای زمان‌بندی شده
- **chat_tracking**: ردیابی چت‌های فعال

تمام داده‌ها در `chat_history.db` ذخیره می‌شوند (به طور خودکار در اولین اجرا ایجاد می‌شود).

## 🔧 گزینه‌های پیکربندی

### متغیرهای محیطی (پیشرفته)

```env
# تنظیمات حافظه و رفتار
RECENT_HISTORY=8              # تعداد پیام‌های اخیر نگه‌داشته شده به صورت کامل
SUMMARIZE_THRESHOLD=40        # تعداد پیام قبل از خلاصه‌سازی
SUMMARIZE_BATCH=30            # پیام‌های فشرده شده در هر مرحله خلاصه‌سازی
STREAM_EDIT_INTERVAL=1.2      # ثانیه بین به‌روزرسانی‌های جریان

# ذخیره‌سازی داده (برای Hugging Face Spaces)
DATA_DIR=/data                # دایرکتوری ذخیره‌سازی دائمی
```

### اجزای کلیدی

- **ChatRepository**: لایه پایگاه داده SQLite ایمن
- **AgnesClient**: تعامل با مدل هوش مصنوعی (چت، خلاصه، تصاویر)
- **RateLimiter**: محدودیت نرخ به ازای هر کاربر و سراسری
- **SpamTracker**: حفاظت از اسپم انفجاری
- **Reminder Scheduler**: دیمون پس‌زمینه برای اعلان‌های زمان‌بندی شده
