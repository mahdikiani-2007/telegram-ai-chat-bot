# External integrations

| Service | Purpose | Called from | Auth (env var, never values) | Quirks handled in code |
|---|---|---|---|---|
| Agnes/OpenCode chat LLM (`CHAT_API_BASE`, model `CHAT_MODEL`) | All chat, vision, `/tr`, `/tldr`, digest writeup, fact extraction, profiler, debate turns, search-decision | `ai.py: AgnesClient` (`stream_chat/generate/summarize`); every handler via `agnes` | `CHAT_API_KEY` (falls back to `AGNES_API_KEY`) Bearer | Router fans out to flaky backends → retry-before-content (`CHAT_RETRY_ATTEMPTS`+1, 0.6s backoff); never retry mid-stream; SSE `data:` parsed as UTF-8; 429 vs `network_error` surfaced distinctly |
| Agnes image (`AGNES_BASE`, model `IMAGE_MODEL`) | `/pic` generation (URL → fetched → `send_photo`) | `handlers/basics.py: handle_image_generation` via `agnes.generate_image` | `IMAGE_API_KEY` (falls back to `AGNES_API_KEY`) Bearer | Non-200 → exception path edits placeholder; `METRICS llm_errors` + throttled admin notify |
| Tavily web search | Chat grounding (`maybe_web_search*`), digest sections | `services/search.py`, `services/digest.py` | `TAVILY_API_KEY` (absent = feature silently off) | `DailyBudget` cap (`TAVILY_DAILY_LIMIT`, UTC reset); decision-LLM fails closed; digest shares the same budget on purpose |
| Telegram Bot API (cloud or Local Server) | All send/receive; upload cap 49MB cloud vs ~1950MB local | `infra.py` patches `apihelper.API_URL/FILE_URL` + `CUSTOM_REQUEST_SENDER`; `bots.py` instances | `TELEGRAM_TOKEN`, `TELEGRAM_TOKEN_LIGHT` (optional 2nd bot) | `LOCAL_BOT_API_URL` switches base URLs; `start.sh` boots `telegram-bot-api` (needs `TG_API_ID/HASH`) and waits ≤30s; photo fetch uses `TELEGRAM_FILE_BASE_URL` |
| Instagram via yt-dlp | Paste-link downloads (post/reel/carousel/story/highlight/share) + guest-mode route + relay downloads | `services/media.py: download_instagram_post` ← handlers.medialink, surfaces guest, ig_relay | `INSTAGRAM_COOKIES_FILE` (Netscape txt, optional, strongly recommended) | Pre-muxed (non-DASH) format preferred so no ffmpeg needed; photo posts unsupported by yt-dlp by design → OG-tag scrape fallback (with cookies); stories need login; single-file guest replies via pre-upload `file_id` trick |
| Instagram via instagrapi (private API) | `ig_relay` group-DM polling only | `ig_relay.py: InstagramRelay` | `IG_RELAY_USERNAME/IG_RELAY_PASSWORD` (dedicated account) + `ig_relay_session.json` | 2FA via `/relay verify`; `ChallengeRequired` → silent backoff (`IG_RELAY_CHALLENGE_BACKOFF`) since polling prolongs checkpoints; thread baseline-seed skips history |
| YouTube via yt-dlp (+ffmpeg, +deno) | Link → quality picker → download → send | `services/media.py` ← handlers.medialink | `YOUTUBE_COOKIES_FILE` (optional); `YOUTUBE_MAX_HEIGHT` cap | System ffmpeg preferred, imageio-ffmpeg fallback, else progressive-only; EJS challenges need `deno` on PATH; cookie→anonymous→android-player fallback ladder; merge retry mp4→matroska; oversize → Pyrogram userbot send |
| Telegram userbot via Pyrogram/MTProto | >cap large-file delivery into the chat directly | `services/media.py: send_large_file_via_userbot` (own thread+event loop) | `TG_API_ID/HASH/SESSION_NAME/SESSION_DIR` + pre-made `.session` file | No-op unless session file exists; account must be a *member* of target groups; `file_id`s not shareable with bot token |
